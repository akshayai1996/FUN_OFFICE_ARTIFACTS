The folder link opens local or network paths directly — if your browser blocks it, use Copy Path and paste into File Explorer. Mapped drive letters (X:\...) are specific to each PC — set them up once under ⚙ Drive Mappings so links resolve to the real network (UNC) path everywhere.

Drive Mappings

Map each mapped drive letter to its real network (UNC) path. Once set, any path typed as X:\... resolves to \\server\share\... automatically when opened or copied — so it works from any PC, not just yours. Find the UNC path via net use in Command Prompt, or right-click the drive in File Explorer → Properties.
